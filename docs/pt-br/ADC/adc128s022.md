# Controlador do conversor A/D ADC128S022 (DE0-Nano)

🌐 [Português](../../pt-br/ADC/adc128s022.md) · [English](../../en/ADC/adc128s022.md)

## 1. O que é

Controlador de barramento do conversor A/D de oito canais e 12 bits da DE0-Nano. Uma máquina de varredura (`adc_sweep`) pede ao chip um quadro SPI de 16 clocks por canal, em ordem, e guarda o resultado de cada canal num registrador de 12 bits. O software só lê os registradores `CH0` a `CH7`, sem conduzir o SPI.

| Bloco | Função |
| :--- | :--- |
| `spi_master` | Mestre SPI de uma palavra, aqui no modo 3 com palavras de 16 bits |
| `adc_sweep` | Varredura dos oito canais, registradores de canal, estado, divisor e interrupção |
| `adc128s022` | Topo com o sincronizador de ADC_SDAT, a seleção de chip e a palavra de endereço do canal |

## 2. Pinos e placa

O manual da DE0-Nano (seção 3.6, tabela 3-9) lista os quatro pinos do conversor. As entradas analógicas IN0 a IN7 vão ao conector de 2x13 pinos (figuras 3-10 e 3-11 da mesma seção).

| Porta do periférico | Sentido | Nome no manual | Pino do FPGA | Descrição do manual |
| :--- | :--- | :--- | :--- | :--- |
| `o_adc_cs_n` | saída | `ADC_CS_N` | `PIN_A10` | Seleção de chip |
| `o_adc_saddr` | saída | `ADC_SADDR` | `PIN_B10` | Dado de entrada do conversor |
| `i_adc_sdat` | entrada | `ADC_SDAT` | `PIN_A9` | Dado de saída do conversor |
| `o_adc_sclk` | saída | `ADC_SCLK` | `PIN_B14` | Relógio de entrada do conversor |

Todos em 3,3 V. O manual dá a taxa de conversão de 50 a 200 ksps e a faixa de 0 a 3,3 V da demonstração de leitura (seção 8.3).

## 3. Parâmetros e portas

| Parâmetro | Padrão | Significado |
| :--- | ---: | :--- |
| `clock_hz` | 50000000 | Frequência do clock do módulo, em hertz |
| `sclk_hz` | 3200000 | Frequência de ADC_SCLK depois do reset, em hertz |
| `channel_latency` | 1 | Quadros entre endereçar um canal e receber o seu resultado (0 ou 1) |

O divisor de reset é $\lceil clock\_hz / (2 \cdot sclk\_hz) \rceil - 1$, que mantém ADC_SCLK em `sclk_hz` ou abaixo. Com 16 clocks por conversão, a faixa de 50 a 200 ksps do manual corresponde a

$$ f_{SCLK} = 16 \cdot f_{amostra} \in [0{,}8 ; 3{,}2] \ \text{MHz} $$

As portas do barramento são `i_clk`, `i_rst`, `i_write`, `i_address` (4 bits), `i_data_in`, `o_data_out` e `o_irq`, mais os quatro pinos da seção 2. A janela do bloco ocupa 11 palavras e não há efeito de leitura.

## 4. Quadro SPI

Cada quadro é uma palavra de 16 bits no modo 3 (ADC_SCLK em repouso alto, o chip muda ADC_SDAT na borda de descida e o controlador amostra na de subida), bit mais significativo primeiro, com ADC_CS_N em nível baixo durante o quadro.

| Bits | Em ADC_SADDR (controlador para o chip) | Em ADC_SDAT (chip para o controlador) |
| :--- | :--- | :--- |
| 15:14 | sem efeito (zero) | zero |
| 13:11 | endereço do canal (ADD2 a ADD0) | zero (os dois primeiros) e depois os 2 bits altos do resultado |
| 10:0 | sem efeito (zero) | resultado, até o bit 0 |

A palavra recebida tem quatro zeros e o resultado de 12 bits nos bits 11:0. Com `channel_latency` em 1 o resultado de um quadro é o do canal endereçado no quadro anterior, então a varredura tem 9 quadros (um de preparo) e o resultado do quadro $f$ vai ao canal $f - 1$.

### 4.1. Origem de cada parâmetro

A folha de dados do ADC128S022 não está no repositório, então só o que o manual diz é confirmado.

| Item | Origem |
| :--- | :--- |
| Quatro pinos, 12 bits, 8 canais, 50 a 200 ksps, 3,3 V | Confirmado pelo manual da DE0-Nano (seção 3.6) |
| Modo 3, palavra de 16 bits, endereço nos bits 13:11, quatro zeros à frente do resultado | Não confirmado; suposição do controlador e do modelo de teste |
| Atraso de um quadro entre endereço e resultado | Não confirmado; o parâmetro `channel_latency` permite trocar sem alterar o resto |
| Tempo mínimo com a seleção em nível alto entre quadros | Não confirmado; o controlador mantém pelo menos dois ciclos |

## 5. Registradores

| Palavra | Nome | Acesso | Reset | Descrição |
| ---: | :--- | :--- | ---: | :--- |
| 0 a 7 | `CH0` a `CH7` | R | 0 | Bits 11:0, último resultado do canal |
| 8 | `CONTROL` | R/W | 0 | Varredura e interrupção (tabela abaixo) |
| 9 | `STATUS` | R/W1C | 0 | Estado da varredura (tabela abaixo) |
| 10 | `DIVIDER` | R/W | seção 3 | Bits 15:0, divisor de clock de ADC_SCLK |

| Bit de `CONTROL` | Nome | Significado |
| ---: | :--- | :--- |
| 0 | `ENABLE` | Varredura contínua; ao desligar, a varredura em andamento termina e para |
| 1 | `IRQ_ENABLE` | Interrupção enquanto `SWEEP_DONE` vale 1 |
| 2 | `START` | Escrever 1 inicia uma varredura com `ENABLE` em 0; lê sempre 0 |

| Bit de `STATUS` | Nome | Acesso | Significado |
| ---: | :--- | :--- | :--- |
| 0 | `BUSY` | R | Há um quadro pedido ou em andamento |
| 1 | `SWEEP_DONE` | W1C | Uma varredura terminou; um evento novo vence a limpeza |
| 2 | `VALID` | R | Uma varredura inteira já terminou desde o reset |

A saída `o_irq` é de nível e vale `SWEEP_DONE` com `IRQ_ENABLE`.

## 6. Uso pelo software

O exemplo em C liga a varredura contínua, espera a primeira varredura e converte o canal 0 em milivolts. A conversão usa a faixa de 0 a 3,3 V da demonstração do manual, de modo que $V = \text{código} \cdot 3300 / 4096$ em milivolts.

```c
#include <stdint.h>

/* Base do periférico, definida pela plataforma. */
#define ADC_BASE ((volatile uint32_t *)0x40001000u)

enum { CH0 = 0, CONTROL = 8, STATUS = 9, DIVIDER = 10 };
enum { ENABLE = 1u << 0, IRQ_ENABLE = 1u << 1, START = 1u << 2 };
enum { BUSY = 1u << 0, SWEEP_DONE = 1u << 1, VALID = 1u << 2 };

#define ADC_FULL_SCALE_MV 3300u

/* Liga a varredura contínua e espera a primeira varredura inteira. */
void adc_start(void)
{
    ADC_BASE[CONTROL] = ENABLE;
    while ((ADC_BASE[STATUS] & VALID) == 0) {
    }
}

/* Devolve o último resultado de 12 bits do canal (0 a 7). */
uint32_t adc_code(unsigned channel)
{
    return ADC_BASE[CH0 + channel] & 0xFFFu;
}

/* Converte o resultado do canal em milivolts. */
uint32_t adc_millivolts(unsigned channel)
{
    return (adc_code(channel) * ADC_FULL_SCALE_MV) / 4096u;
}

/* Faz uma única varredura sem ficar em modo contínuo. */
void adc_sweep_once(void)
{
    ADC_BASE[STATUS] = SWEEP_DONE;
    ADC_BASE[CONTROL] = START;
    while ((ADC_BASE[STATUS] & SWEEP_DONE) == 0) {
    }
}
```

## 7. Verificação

O teste de entidade liga o controlador a um modelo do conversor que confere o quadro de 16 clocks, o endereço de cada canal e a seleção de chip, e devolve oito tensões conhecidas. Os casos cobrem os pinos em repouso, uma varredura única com os nove quadros e a leitura de cada tensão, a varredura contínua que acompanha uma tensão que muda, a interrupção e o limite de ADC_SCLK. O modelo repete as suposições da seção 4.1 e as marca no código. O teste da máquina de varredura roda com `channel_latency` 1 e 0 e confere os registradores, a varredura única e a contínua, a parada com `ENABLE` desligado e a interrupção. A prova formal verifica o quadro (seleção de chip, 16 bordas, endereço do canal em ADC_SADDR, pulso de conclusão) e a máquina de varredura (canal pedido, nove quadros, resultado no canal certo, estado, marcas e interrupção), com mutantes que ela precisa reprovar. A leitura de uma tensão conhecida na placa depende de um teste de bancada.
